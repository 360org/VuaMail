## Architecture Notes

- **PST reader is a stub** — only validates magic header bytes, returns hardcoded folder names.
- **mail-engine is pure-TS, zero deps** — all networking/storage/auth in `apps/mail/src/main/`. Clean separation to preserve.
- **Monorepo healthy outside mail** — 415+ test files across docs/sheets/slides/pdf/markdown.
- **TASKS.md / ROADMAP.md misleading** — all phases checked off but OAuth, SMTP AUTH, SQLite are non-functional.
